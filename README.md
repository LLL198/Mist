## 认识 Mist

管理媒体服务，往往还需要处理账号、线路、播放记录、求片和群消息。Mist 将这些工作放进同一个平台，让管理员集中管理，让用户自助完成日常操作。

你可以在 Web 后台管理多台 Emby 服务器，也可以通过 Telegram 提供账号查询、求片、续费和通知服务。积分、抽奖、雾袋与群聊游戏，则为社区提供更多互动方式。


## 适合怎样使用

| 你的需求 | Mist 可以帮助你 |
| --- | --- |
| 管理多台 Emby 服务器 | 集中配置服务器、用户、访问线路和媒体库权限 |
| 减少重复的账号维护 | 管理注册、有效期、续费、批量操作和到期通知 |
| 了解播放与访问情况 | 查看正在播放、历史记录、用户分析和并发情况 |
| 为用户提供自助服务 | 提供个人中心、求片、工单、账号绑定和积分兑换 |
| 运营 Telegram 社区 | 使用机器人处理账号服务、推送通知和组织积分活动 |

## 功能一览

### 服务器与账号，集中管理

从添加服务器到管理用户，把日常维护放在同一处。

- **多服务器接入**：管理 Emby 地址、API Key、对外访问地址和线路。
- **账号管理**：创建、查询、编辑、启用、禁用、删除用户及重置密码。
- **有效期管理**：管理账号到期时间，支持批量延期与续费记录查询。
- **注册与邀请**：配置用户注册、邀请码和账号卡密，查看注册记录。
- **角色与权限**：区分普通用户、管理员和分销商，分配管理菜单权限。
- **用户同步**：按需进行跨服务器用户同步和对比。
- **媒体库权限**：配置全局或指定用户的媒体库访问范围。

### 播放与访问，看得清楚

了解服务器正在发生什么，也能回看一段时间内的使用情况。

- 实时查看正在播放的内容、客户端、状态和播放进度。
- 查询播放记录、热门影片、用户排行和播放趋势。
- 按用户、设备、IP 和地区查看播放汇总。
- 查看用户播放时长、活跃度及相关统计。
- 配置同时播放限制、客户端与地区访问规则。
- 查询访问拦截记录，设置需要排除的用户。

### 从发现影片，到提交求片

用户可以浏览内容、表达需求，管理员可以跟进处理。

- **媒体浏览**：查看影片、剧集、分季分集、演职人员和媒体信息。
- **影片搜索**：接入 TMDB，搜索电影与剧集，查看热门内容和预告片。
- **求片管理**：提交整部或按季求片，配置次数限制，审核并跟踪入库状态。
- **订阅服务**：接入 MoviePilot，管理订阅、查看缺集和取消订阅。
- **追新日历**：查看 TMDB 追新内容，配置定时同步和消息推送。
- **工单沟通**：用户提交问题，管理员回复和处理。

### 用户中心，日常操作自己完成

提供密码登录与 Telegram 登录，支持多服务器账号选择。用户可以管理个人资料、密码、头像和联系方式，绑定账号，查看可用线路，以及查询积分流水和兑换记录。

页面入口根据角色与站点配置显示。界面支持桌面和移动端访问，并提供主题切换与 PWA 安装入口。

### 积分与互动，让社区更有参与感

- 签到、连续签到奖励、发言积分与排行榜。
- 积分转账、账号兑换、续费和奖品兑换。
- 抽奖、积分红包、雾袋及领取记录。
- 等级、奖品、兑换规则与积分调整。
- Brain 脑力挑战、三国杀、21 点、骰子、地狱骰、老虎机和雾中刮刮乐。

### 分销、支付与站点运营

按站点需求配置账号服务和运营规则。

- 分销商查看积分、用户、卡密和经营数据。
- 管理进货申请、商品兑换、审核与兑换记录。
- 配置售卡套餐、支付方式、订单超时和查单规则。
- 查询支付订单、重新查单和人工确认发卡。
- 发布站内公告，配置通知渠道与消息模板。
- 查看实时日志，管理定时任务并按需立即执行。

> 账号卡密、续费和支付用于站点提供的 Emby 用户服务，与 Mist 产品授权无关。

## Telegram 里的 Mist

把常用服务放进聊天窗口。用户通过机器人操作，管理员通过机器人处理，重要事件通过消息及时送达。

| 场景 | 机器人功能 |
| --- | --- |
| 账号自助 | 查询账号和线路、绑定与解绑、注册、卡密开号与续费 |
| Web 登录 | 通过 Telegram 登录站点 |
| 影片求片 | 私聊搜索、内联搜索、提交求片和查询入库情况 |
| 积分活动 | 签到、排行榜、转账、兑换、抽奖、红包和雾袋 |
| 管理操作 | 用户管理、绑定审批、批量延期、卡密生成和公告 |
| 群聊管理 | 配置管理员操作权限、禁言及群成员相关管理 |
| 事件通知 | 媒体入库、播放动态、用户到期、求片处理和排行榜 |

配置好机器人后，可通过以下入口开始：

```text
/start           打开服务面板
/request 片名    搜索并提交求片
```

内联求片可使用 `@机器人用户名 片名`。具体入口取决于站点配置，内联功能和群管理操作需为机器人启用对应能力与权限。

## 开始使用

### 准备

建议使用至少 **2 核 CPU、4 GB 内存**的部署机器，并安装 Docker 和 Docker Compose v2。准备好 Emby 服务器地址与 API Key，再按[部署教程](docs/DEPLOYMENT.md)放置部署产物、设置环境变量和 Web 转发。

### 启动

在项目根目录执行：

```bash
docker compose -f docker-compose.mist.yml up -d --build
docker compose -f docker-compose.mist.yml ps
```

默认在部署机器上访问：

```text
http://127.0.0.1:8082
```

### 完成首次配置

1. 按页面提示初始化管理员并登录。
2. 添加 Emby 服务器，填写连接地址和 API Key。
3. 设置用户访问地址、线路与媒体库权限。
4. 按需开启求片、积分、Telegram 和通知功能。

域名、HTTPS、远程访问、升级与备份的操作见[部署教程](docs/DEPLOYMENT.md)。

## 按需连接你的服务

| 服务 | 用途 | 准备内容 |
| --- | --- | --- |
| Emby | 媒体服务与账号管理 | 服务器地址、API Key |
| TMDB | 影片搜索、求片与追新日历 | 对应 API 凭据 |
| MoviePilot | 求片订阅与缺集管理 | 服务地址及连接参数 |
| Telegram | 账号服务、群互动与通知 | 机器人 Token、群组及操作权限 |
| 通知渠道 | Telegram、钉钉、企业微信等消息推送 | 对应渠道的连接参数 |
| 支付服务 | 站点售卡与订单处理 | 支付渠道参数及套餐配置 |

服务器、域名及第三方服务费用由部署者自行承担。

## 常见问题

<details>
<summary><strong>可以只使用 Web 管理后台吗？</strong></summary>

可以。Telegram、支付及其他外部服务按需配置，使用对应功能时再启用。

</details>

<details>
<summary><strong>为什么其他机器打不开默认地址？</strong></summary>

默认 Web 端口仅绑定部署机器的本地地址。局域网访问需要调整端口绑定与允许来源；使用域名时可配置 HTTPS 反向代理。具体步骤见部署教程。

</details>

<details>
<summary><strong>更新前需要备份哪些内容？</strong></summary>

保存应用数据、MySQL 数据、Redis 数据、环境变量及部署配置。目录备份前应停止服务，操作步骤见部署教程的“备份与恢复”。

</details>

<details>
<summary><strong>为什么不同账号看到的功能不一样？</strong></summary>

页面和机器人入口会根据用户角色、菜单权限和站点配置显示。部分功能还需要对应第三方服务的凭据。

</details>
