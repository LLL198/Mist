# Mist 功能预览

[返回项目首页](../README.md) · [部署教程](DEPLOYMENT.md)

Mist 使用浅蓝与白色界面，支持桌面和移动端访问。部署后可通过以下入口体验主要功能：

| 页面 | 功能 |
| --- | --- |
| 登录页 | 账号密码登录、Telegram 登录和管理员初始化 |
| 仪表盘 | 服务器概况、媒体统计、最新入库和热门内容 |
| 媒体库与求片 | 浏览影片、搜索内容、提交求片并查看处理进度 |
| 用户中心 | 个人资料、账号绑定、积分和兑换记录 |
| 管理后台 | 用户、服务器、播放统计、任务与系统配置 |

默认访问地址为 `http://127.0.0.1:8082`。页面入口随用户权限和站点配置显示，远程访问方式见部署教程。
